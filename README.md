# Instyment - Универсальная модульная платформа инструментов

**Instyment** — это мощная и быстрая web-платформа, объединяющая в себе набор полезных инструментов для работы с изображениями, PDF-документами и утилитами для разработчиков. 

Проект построен по модульной архитектуре: каждый инструмент — это независимый модуль, который автоматически сканируется и добавляется в меню. Это позволяет легко расширять платформу без раздувания главного файла.

## 🛠️ Доступные модули

### 🖼️ Изображения
- **Конвертер изображений**: Массовая конвертация форматов (JPG, PNG, WEBP, GIF, BMP).
- **Сжатие изображений**: Массовое сжатие (оптимизация размера) картинок.
- **Удаление фона (AI)**: Нейросетевое удаление фона с фото в 1 клик с помощью U2Net (rembg).
- **Водяной знак**: Массовое наложение текста (с выбором цвета и размера) на картинки.
- **Палитра цветов**: Анализ фото и извлечение 5 доминирующих HEX-цветов.

### 📄 Документы PDF
- **Разделение PDF**: Извлечение отдельных страниц или диапазонов из многостраничного PDF.
- **PDF в Изображения**: Конвертация каждой страницы PDF в отдельную картинку (JPG/PNG).
- **PDF в Word (.docx)**: Полное извлечение текста и таблиц с сохранением структуры.
- **PDF в Excel (.xlsx)**: Извлечение всех таблиц из PDF документа в Excel (постранично).
- **Установка пароля на PDF**: Защита документов надёжным паролем.

### 💻 Для разработчиков
- **JWT Декодер**: Безопасная расшифровка Header и Payload токенов прямо в браузере (без отправки на сервер).
- **Форматировщик кода (Beautifier)**: Приведение "каши" из кода в читаемый вид (поддержка JSON, JS, HTML, CSS, SQL) на базе Prettier.
- **Сравнение текстов (Text Diff)**: Визуальное сравнение двух текстов с подсветкой зелёным (добавлено) и красным (удалено) на базе jsdiff.

## 🚀 Особенности архитектуры
- **Никаких огромных `index.php`**: Роутер компактный, а вся логика лежит в `tools/{категория}/{модуль}/`.
- **Авто-обнаружение**: Платформа автоматически находит файлы `manifest.json` в папках инструментов и выводит их в меню с нужным тегом, иконкой и описанием.
- **Архивирование на лету**: Все модули, работающие с массивом файлов (разделение, конвертация), умеют отдавать результат в едином ZIP-архиве (`Скачать всё`).
- **Стек**: PHP 8 (бэкенд роутинг и обработка), Python 3 (нейросети и сложный PDF-парсинг), Vanilla JS (современный реактивный фронтенд без тяжелых фреймворков), CSS Variables (цветовые схемы).

## 🐳 Запуск через Docker (Рекомендуется)

Проект полностью докеризирован и включает все необходимые зависимости (PHP GD, Python, rembg, PyPDF2 и др.).

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/GrinRonm/ToolingRegs.git
cd ToolingRegs

# 2. Запустите Docker Compose
docker-compose up -d --build
```

После сборки проект будет доступен по адресу: **http://localhost:8080**

> **Примечание:** При первом использовании модуля "Удаление фона", нейросеть скачает модель (~170MB). Это может занять несколько секунд, после чего модуль будет работать моментально.

## ⚙️ Установка вручную (Без Docker)

Если вы хотите запустить проект локально без Docker, вам потребуется:
- PHP 8.1+ (с расширениями `sqlite3`, `gd`, `zip`, `mbstring`)
- Python 3.10+ и `pip`

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/GrinRonm/ToolingRegs.git
cd ToolingRegs

# 2. Установите Python зависимости
pip3 install rembg==2.0.40 pdf2docx pdfplumber==0.7.3 pandas openpyxl PyPDF2 pillow

# 3. Убедитесь, что папка storage/ доступна для записи
chmod -R 775 storage/

# 4. Запустите встроенный сервер PHP
php -S localhost:8000
```
Откройте `http://localhost:8000` в браузере.

## 📁 Создание новых модулей
Чтобы добавить новый инструмент, создайте папку `tools/category/my-tool/` со следующими файлами:
1. `manifest.json` - Метаданные (название, иконка, описание).
2. `handler.php` - Бэкенд-логика обработки файлов/данных (возвращает массив или вызывает ошибку `Response::error`).
3. `view.php` - HTML интерфейс модуля.
4. `script.js` - Логика отправки данных на сервер через `fetch`.

Документация по созданию расширена в [CREATING_TOOL.md](docs/CREATING_TOOL.md).
